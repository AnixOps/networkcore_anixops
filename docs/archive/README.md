# Documentation Archive

This directory holds completed implementation plans and superseded design notes.
Archived material is retained for historical context only and is not a source of
current product, release, CI, or operational requirements.

## 2026-07 Completed Plans

`2026-07-completed-plans/` contains the execution plans and design notes for
the signed SD-WAN delivery verifier and the initial Windows EasyTier foreground
tunnel implementation. Their resulting code, contracts, and active operational
requirements remain in the workspace and current architecture documentation.

## TODO Completed Items (2026-10)

`todo-completed-2026-10.md` keeps the full "已完成" checklist that lived in
`TODO.md` until 2026-10-22, verbatim, for audit history.

## 2026-10 Removed Engines

`2026-10-removed-engines/` keeps the source contracts of the third-party engine
adapters removed on 2026-10-26, and the manual acceptance plan of the Windows
foreground tunnel removed the same day. The embedded engine replaced the
adapters on every platform; SD-WAN networking will return on the ANX private
protocol.
